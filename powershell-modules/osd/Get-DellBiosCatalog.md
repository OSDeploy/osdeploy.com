# Get-DellBiosCatalog

Returns the BIOS Component of the Dell System Catalog

| Property | Value |
|---|---|
| Module | OSD |
| Platform | WinPE (amd64 / arm64) |

## Description

Returns the BIOS Component of the Dell System Catalog

## Syntax

```powershell
Get-DellBiosCatalog [-Compatible] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `-Compatible` | `SwitchParameter` | False | Limits the results to match the current system |
