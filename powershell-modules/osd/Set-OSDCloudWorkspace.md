# Set-OSDCloudWorkspace

Sets configuration values by using Set-OSDCloudWorkspace.

| Property | Value |
|---|---|
| Module | OSD |
| Platform | WinPE (amd64 / arm64) |

## Description

Provides the implementation for Set-OSDCloudWorkspace.

## Syntax

```powershell
Set-OSDCloudWorkspace [[-WorkspacePath] <String>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `-WorkspacePath` | `String` | False | Specifies the value for WorkspacePath. |
