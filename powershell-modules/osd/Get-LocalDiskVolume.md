# Get-LocalDiskVolume

Gets LocalDiskVolume information.

| Property | Value |
|---|---|
| Module | OSD |
| Platform | WinPE (amd64 / arm64) |

## Description

Returns LocalDiskVolume data for the current system or OSD session context.

## Syntax

```powershell
Get-LocalDiskVolume [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## Parameters

This function does not define function-specific parameters beyond common parameters.

## Examples

### Example
```powershell
Get-LocalDiskVolume
Demonstrates a common way to run Get-LocalDiskVolume.
```
