# Get-OSDCloudVMDefaults

Gets the OSDCloudVM Module defaults from $Global:OSDModuleResource.NewOSDCloudVM

| Property | Value |
|---|---|
| Module | OSD |
| Platform | WinPE (amd64 / arm64) |

## Description

Gets the OSDCloudVM Module defaults from $Global:OSDModuleResource.NewOSDCloudVM

Get-OSDCloudVMDefaults [-ProgressAction <ActionPreference>] [<CommonParameters>]
