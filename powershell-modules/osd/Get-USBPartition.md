# Get-USBPartition

Gets USBPartition information.

| Property | Value |
|---|---|
| Module | OSD |
| Platform | WinPE (amd64 / arm64) |

## Description

Returns USBPartition data for the current system or OSD session context.

## Syntax

```powershell
Get-USBPartition [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## Parameters

This function does not define function-specific parameters beyond common parameters.

## Examples

### Example
```powershell
Get-USBPartition
Demonstrates a common way to run Get-USBPartition.
```
