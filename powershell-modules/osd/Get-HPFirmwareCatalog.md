# Get-HPFirmwareCatalog

Returns the Firmware Component of the HP System Catalog

| Property | Value |
|---|---|
| Module | OSD |
| Platform | WinPE (amd64 / arm64) |

## Description

Returns the Firmware Component of the HP System Catalog

## Syntax

```powershell
Get-HPFirmwareCatalog [-Compatible] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `-Compatible` | `SwitchParameter` | False | If you have a HP System, this will filter the results based on your Baseboard Product value |
