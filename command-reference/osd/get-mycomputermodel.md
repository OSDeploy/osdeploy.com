# Get-MyComputerModel

Gets MyComputerModel information.

| Property | Value |
|---|---|
| Module | OSD |
| Platform | WinPE (amd64 / arm64) |

## Description

Returns MyComputerModel data for the current system or OSD session context.

## Syntax

```powershell
Get-MyComputerModel [-Brief] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `-Brief` | `SwitchParameter` | False | Specifies the Brief to use when running Get-MyComputerModel. |
