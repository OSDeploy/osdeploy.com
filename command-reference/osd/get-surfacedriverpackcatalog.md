# Get-SurfaceDriverPackCatalog

Returns the Microsoft Surface DriverPack Catalog

| Property | Value |
|---|---|
| Module | OSD |
| Platform | WinPE (amd64 / arm64) |

## Description

Returns the Microsoft Surface DriverPack Catalog

## Syntax

```powershell
Get-SurfaceDriverPackCatalog [-Compatible] [[-DownloadPath] <String>] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `-Compatible` | `SwitchParameter` | False | Limits the results to match the current system |
| `-DownloadPath` | `String` | False | Specifies a download path for matching results displayed in Out-GridView |
