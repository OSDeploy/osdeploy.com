# Get-OSDVolume

Gets OSDVolume information.

| Property | Value |
|---|---|
| Module | OSD |
| Platform | WinPE (amd64 / arm64) |

## Description

Returns OSDVolume data for the current system or OSD session context.

## Syntax

```powershell
Get-OSDVolume [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## Parameters

This function does not define function-specific parameters beyond common parameters.

## Examples

### Example
```powershell
Get-OSDVolume
Demonstrates a common way to run Get-OSDVolume.
```
