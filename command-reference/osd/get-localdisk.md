# Get-LocalDisk

Gets LocalDisk information.

| Property | Value |
|---|---|
| Module | OSD |
| Platform | WinPE (amd64 / arm64) |

## Description

Returns LocalDisk data for the current system or OSD session context.

## Syntax

```powershell
Get-LocalDisk [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## Parameters

This function does not define function-specific parameters beyond common parameters.

## Examples

### Example
```powershell
Get-LocalDisk
Demonstrates a common way to run Get-LocalDisk.
```
