# Get-IntelEthernetDriverPack

Returns the Intel Ethernet Driver Object

| Property | Value |
|---|---|
| Module | OSD |
| Platform | WinPE (amd64 / arm64) |

## Description

Returns the Intel Ethernet Driver Object

## Syntax

```powershell
Get-IntelEthernetDriverPack [-Online] [-UpdateModuleCatalog] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `-Online` | `SwitchParameter` | False | Checks for the latest Online version |
| `-UpdateModuleCatalog` | `SwitchParameter` | False | Updates the OSD Module Offline Catalog |
