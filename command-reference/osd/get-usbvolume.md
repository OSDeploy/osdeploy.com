# Get-USBVolume

Gets USBVolume information.

| Property | Value |
|---|---|
| Module | OSD |
| Platform | WinPE (amd64 / arm64) |

## Description

Returns USBVolume data for the current system or OSD session context.

## Syntax

```powershell
Get-USBVolume [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## Parameters

This function does not define function-specific parameters beyond common parameters.

## Examples

### Example
```powershell
Get-USBVolume
Demonstrates a common way to run Get-USBVolume.
```
